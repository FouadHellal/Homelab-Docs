# Code of conduct

atlas is a small project by and for people who run homelabs. Be the kind of person you'd want
to help debug your own network at 2 a.m.

- Be respectful and patient. Assume good faith, especially with newcomers.
- Critique code and ideas, not people. No harassment, insults or discrimination of any kind.
- Keep other people's data safe. Don't post anyone's credentials, IPs or scan output. Redact
  before you paste.
- Disagreements about direction are settled in the open, in issues, with reasons.

Report problems to the maintainer through GitHub (a private security advisory works for
anything sensitive). The maintainer may edit or remove content, and may block people who don't
follow this code.
